# Flight Search Application

A Java Spring Boot flight search app powered by static flight data.

## Features
- Search flights by origin, destination, and date
- Display results in a clean table
- Includes a REST API

## Run
```bash
mvn spring-boot:run
```

Open:
- http://localhost:8080/
- http://localhost:8080/api/flights?origin=Delhi&destination=Mumbai

## Tech Stack
- Java 17
- Spring Boot 3
- Thymeleaf
- Maven
